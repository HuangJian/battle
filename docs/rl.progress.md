1. **无质变，只有噪声 + 轻微上漂**：胜率全程 2–20，均值约 11/100。单点 ±5pp
   皆噪声（n=100 二项标准差约 ±3–4pp）；block 级上漂显著（13.7 vs 8.9，约 6 SE），
   但绝对值连 40% 平台期线的一半都摸不到，更别说教师的 64。
2. **击杀从未接近 ep60 的 193**：最高是 ep2 的 160（基本还是 warm-start 的底子），
   之后长期 90–150 徘徊——p4 训练拿"开火积极性"换了一点胜率，杀敌效率反而永久
   掉档。§2 的"变怂"诊断（开枪 676 vs 1021）在全程成立。
3. **训练指标健康但学习已平台期**（对照 Colab 日志 ep1–43 + `bc.py`/`dataset.py`
   口径）：train_loss 1.98→1.29 单调降、无 NaN；val 为 shard 级切分（P2-6d）无泄漏，
   train/val gap 稳定 ~0.3；但后 18 epoch val 只降 ~0.06、fire acc +0.006（多数类
   红利，0.86 的 acc 与"不敢开火"并存）；value 头 MSE 全程 0.87–0.95 横盘——
   **BC loss↓ ≠ 能力↑**，帧平均 CE 天然偏好保守策略。
4. **ep22 的 20/100 是噪声（选择效应），但不全是**：平台期 10.7%，单检验二项
   P(≥20/100)=0.0042，但 best-of-45 的 family-wise P≈0.17（1−(1−0.0042)⁴⁵）；
   配对 McNemar：ep22 实赢弱邻居（vs ep21 p=0.0007、vs ep23 p=0.007），但与
   ep27/ep42/ep45 无差异；3 个独赢难种（seed 3/87/98）、零独输——真实水平约
   14–15%，"20" 高估，不做 cherry-pick 依据。附带：最易的 seed 也只被 16/45
   个 ckpt 赢下——全场无一块"已攻克"的领地。

### 3.4 决策：RL 起点用 p1-ep60（待 RL 启动时记 DECISIONS 条目）

1. p4-BC 净效果 = 胜率原地踏步 + 杀伤永久掉档 + p1 遗忘 10pp（94→84），"学差了"
   有全程数据背书。
2. PPO 吃 reward 密度（ep60 杀 193/击中敌 617，信号最密）与探索多样性
   （开火 1021 vs p4 系 ~600）；保守起点易被 KL 锁死，激进起点下 KL 反而是安全带。
3. Value 头无可继承价值（§3.3-3）；架构逐项一致（student / schema 2 / 67656 参数，
   含 value_head，`WEIGHTS.md` 已核），ep60 可直接 drop-in 做 PPO 初始化。
4. 严谨做法：小规模 A/B（ep60 vs ep45，短 PPO 看 early curve）再拍板；默认 ep60。

## §2 p4-onset 四面围攻：BC ep60 vs God-AI（2026-09-04，DECISIONS §327）

> p1（单敌）已被 BC 蒸馏饱和（§1：ep60 94/100 ≈ 教师 92/100）后课程升级：4 敌混编

### 2.2 判读

1. **BC 的 p1 达标不迁移**：单敌 94% → 4 敌 14%，教师同场景只掉到 64%。p1 上学的
   「发现→瞄准→击杀 1 个目标」没有泛化成多目标交战/四向受敌的生存能力——学生每局

2. **教师同样吃力但明显更稳**：God-AI 64%（每局 3.06 杀），且 4 杀=64 局全部真正

3. **cap 语义**：2400 ticks 对 4 敌偏紧但非主因——ep60 仅 12 超时（其中 4 局在

4. **并行==串行复验**：p4-onset 上 god 100 局 15-worker vs 1-worker 行级 diff 逐字节
   一致（新课程无几何 seed 依赖，仅模拟 RNG 流变化）。

  eval_stages 2000-2000）。BC 热启动仍可用——它不是「完成了 p1 就毕业」，而是

## §1 p1-onset 教师-学生基线：BC ep60 vs God-AI（2026-09-04）

> RL 启动前的对照锚点。60 epoch 全量 BC 学生（Colab T4，165K 帧 p1-godai-v2 语料）
> 与它的教师 God-AI 在同课程上各跑 100 局贪心评估——**学生已追平教师**
> （94/100 vs 92/100，统计同水平），BC 热启动质量足够进入 RL 微调。

### 1.1 训练侧（BC 60 epoch 全量，DECISIONS §325）

- 语料：`tmp/p1-godai-v2`（p1-godai 1892 胜局 / 165K 帧，含 returns.npy）。
- 命令：`train/bc.py --data-dir ... --arch student --value-coef 0.5 --epochs 60
  --ckpt-every 1 --batch 256 --lr 0.003 --val-split 0.1 --mirror-p 0.5
  --seed 1234 --device cuda`（Colab T4，~82 s/epoch，总计 4911 s）。

  cosine 尾段（lr 1.89e-3→0）的增益几乎全部落在 power 关（14/25 → 20/25，
  死亡 11 → 5），basic 25/25 补齐，fast/armor 已达天花板。
