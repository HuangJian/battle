#（2026-09-01 事故：dist_common.py 加了 3 个文件、sampler-agent.ts 漏同步）。
#
# 规则：
#   '#' 开头 = 注释；空行忽略；
#   以 '/' 结尾 = 目录，递归纳入其下所有文件（受下方 F3 噪声过滤）；
#   其余 = 具体文件（相对 repo 根、posix 路径；不存在则跳过；单文件条目不过滤）。
# 增删改文件集只改这里，严禁在两侧源码里硬编码清单。
#
# F3 噪声过滤契约（plan/dist-codehash-stale-fix.md，双侧逐条对齐——改任一侧必须同步
# 另一侧，否则全员 stale）：目录递归时跳过——
#   1) 任一路径段以 '.' 开头（隐藏项：.git / .DS_Store / .venv / 编辑器临时文件）；
#   2) 目录名 __pycache__ / node_modules；
#   3) 文件后缀 .pyc .orig .rej .bak .tmp .log .swp 或以 '~' 结尾。
# 保留：*.ts / *.c / *.wasm（src/nn/wasm/conv_feats.wasm 是受跟踪构建产物，仍在集内）。

#   tools/agent/codehash-files.ts isSkippedCodeHashDir/isSkippedCodeHashFile。
