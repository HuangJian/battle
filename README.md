# Battle City Web

> **三十年前，你守着那只像素老鹰，打到天亮。**
> **三十年后，它跑在浏览器里——没有卡带，没有吹灰，按一下 Enter 就开战。**

Battle City Web 是经典红白机《坦克大战》的现代重制：原汁原味的 35 关布局、熟悉的砖墙手感，外加一套为未来十年设计的、干净到能当教科书的游戏架构。打开页面，玩五分钟，带着微笑离开。

---

## 这是什么

一个用 **TypeScript + Canvas 2D** 写成的浏览器坦克大战。零美术资源（精灵全是手写 SVG）、零音频文件（音效全部运行时合成），整个游戏自包含——`bun run dev` 起一个服务，浏览器打开就直接打。

它不只想"复刻情怀"。它想成为**这个永恒玩法最考究的实现**，同时把地基打牢，让明天的模式、关卡、社区内容都能长在今天的引擎上，而不用拆地基。

三条哲学性的文件，各管一摊：

- **[`MANIFEST.md`](MANIFEST.md)** — 项目的信条（为什么做、什么不能动）。
- **[`docs/features.md`](docs/features.md)** — 功能全景（你能玩到什么、怎么实现的）。
- **[`docs/architecture.md`](docs/architecture.md)** — 架构记录（决策、技术选型、未来扩展的接缝）。

想理解"灵魂"去读 MANIFEST；想看"玩法清单"去读 features；想知道"怎么搭的"去读 architecture。本文件只做总体介绍和入口。

## 你能玩到什么

- **35 个正版 FC 关卡** —— 13×13 数字地块码被无损展开成 26×26 子格网格，当年那堵让你卡关的墙，分毫不差。
- **六类道具** —— 星星（全维升级）、炸弹（清屏）、护盾、冰冻、加命、头盔。
- **四种敌车 × 指挥官 AI** —— 新兵/士兵/老兵/指挥官四档智能，全是**配置不是代码**；高难度下会选举指挥官带队包抄。
- **六维战斗系统** —— 每辆坦克由火力/弹速/火控/机动/装甲/特殊描述，数值由能力卡推导；对枪公平、子弹永远追得上坦克这些不变量被测试钉死。
- **时光回溯** —— 基地被打爆不甩你 GAME OVER，而是问你：回到 30 秒前？60 秒前？还是重打？后台每秒静默存档。
- **四档难度** —— Relax / Classic / Hard / Chaos，主要提升敌人"智商"而非数值。
- **三套主题** —— Classic / Neon / Modern Retro，换主题只换颜色数据，玩法零变化。

更细的清单、数值、道具机制都写在 **[`docs/features.md`](docs/features.md)**。

## 怎么搭的（三十秒速览）

```
Input → Simulation → World → Renderer / Audio / UI
```

一条铁律撑起一切：**只有 `Simulation` 能改 `World`**，其余全部只读。这条线换来了确定性（同种子+同输入=逐帧一致的重演）、无隐藏状态（一份快照=完整世界）、可抛弃的表现层（回溯/回菜单时视觉全弃重建，从 World 重来）。

- **确定性**：固定 60Hz 时间步 + 种子化 RNG，所有熵走 `world.rng`。
- **数据高于代码**：坦克/关卡/难度/主题/AI 全是 `config/`，加内容 = 加一行数据。
- **零素材**：30 个手写 SVG 预光栅化为位图缓存；Web Audio 实时合成音效。
- **性能**：稳态零分配、增量地形重绘、场景签名驱动的按需跳帧——风扇不转。

完整的技术选型表、分层职责、GameEvent 跨层通道、回溯与重演的预备设计，全部在 **[`docs/architecture.md`](docs/architecture.md)**。

## 技术栈

| 关注点 | 选型 |
|---|---|
| 语言 | TypeScript（`strict`） |
| 工具链 | Bun（运行 + 测试 + 包管理） |
| 构建 / 开发 | Vite（目标 es2020） |
| 渲染 | Canvas 2D（仅战场，416×416） |
| 样式 | CSS 变量（主题注入） |
| 资源 | 手写 SVG → 预光栅化位图缓存 |
| 音频 | Web Audio API 合成 |
| 存储 | localStorage（设置 + 最高分） |

## 快速上手

```bash
bun install        # 装依赖
bun run dev        # 起开发服（默认 :3000），浏览器打开即玩
bun run build      # 构建产出（oxlint && tsc && vite build）
bun run test       # 跑测试（75 个用例的弹药库）
bun run check      # 全量门禁：test + typecheck + lint + format
```

> 要求 **Bun** 运行时。没有 npm 那套分裂的体验。

操控：WASD / 方向键移动，空格开火，P 暂停，R 回菜单，按键可在设置面板里改。
